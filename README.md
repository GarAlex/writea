# WriteA

Native app for **vector illustration, page layout, and a real word processor** on one canvas.

[writea.com](https://writea.com) · [Mac App Store](https://apps.apple.com/us/app/writea/id980892066) · [Microsoft Store](https://apps.microsoft.com/store/detail/9P18DGSDVQCR)

Most tools treat a document as either free-form pages or one continuous flow of text. WriteA does both. A page is just a page, and your text is one story that can run through as many pages as it needs. Type past the bottom and it continues onto the next page — no separate “flowing text mode” bolted onto a design canvas.

Built for work that needs drawing, layout, and writing at once: flyers, zines, reports, comics, manuals, posters, newsletters, and books.

No subscription. Documents are files on your machine — no account, no cloud lock-in.

## Highlights

- **Draw** — pen / Bézier, shapes, brushes, gradients, masks, convert-to-outlines
- **Lay out** — multi-page docs, masters, guides, tables, wrap text around art
- **Write** — styles, lists, footnotes; on Mac: endnotes, comments, spell check, font editor
- **Import** — Word, PDF, RTF, images (SVG on Mac); OCR text out of a screenshot
- **Native + fast** — GPU canvas, Rust core shared across platforms
